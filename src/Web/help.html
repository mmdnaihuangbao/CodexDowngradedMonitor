Codex 降智雷达 0.5

双击 start.bat 或 EXE 启动；双击 stop.bat 关闭。无需安装 Python、Rust 或 Visual Studio。面板地址由启动器显示，默认是 localhost:48778。

从旧版升级

先正常关闭旧版，将旧目录中的 config.json 和整个 data 目录复制到新目录，再启动。无需导入、转换数据或重新配置。不要只复制正在使用的 SQLite 主文件而遗漏 WAL。

便携目录

程序自行保存的文件只在 EXE 同目录的 config.json 和 data 内。日志为 data/logs/collector.log。目录不可写会报错，不会回退 AppData 或用户临时目录。Codex 的日志和会话目录是只读输入。

控制与排障

CodexDowngradedMonitor.exe --status 查看实际端口和阶段；--stop 通过命名管道关闭，不依赖网页和 HTTP。相同 Windows 用户跨目录只运行一个主服务和至多一个 worker。旧版仍持有单例锁时，先用旧版停止脚本关闭。

配置继续使用 version=0.1 和 cpp_port 字段名；历史数据版本仍是 0.3。设置页面可以修改预期模型、扫描间隔和线程数。日志清屏不会删除历史。

观测边界

本工具是实验性本地观测工具。协议中的模型字段不能证明实际模型权重或能力；缺少请求证据时不作降级结论。只读取进程内存和本地日志，不向外部上传数据。使用前应确认自己有权进行相应观测。
